# Space terrain

Plays any standard Wesnoth map in space. When a game starts, a Lua script swaps every hex's
Wesnoth terrain for a space terrain (Z codes). Each space terrain is an alias of the terrain it
replaces, so movement, defence, villages, healing, income and castles all play exactly as on the
original map. Only the look changes. The mapping and the reasons for it are in
[`design/space-tileset.md`](../design/space-tileset.md).

Tested in Wesnoth 1.16 (the screenshot mode and a headless multiplayer game); the WML and Lua
use only APIs that 1.18 keeps.

## Using it

The add-on's `_main.cfg` includes this folder in every mode, before the era:

```
#ifhave ~add-ons/Dominion_War_Wesnoth/terrain/_main.cfg
{~add-ons/Dominion_War_Wesnoth/terrain}
#endif
```

That defines the terrain types, their drawing rules, and the macro `{DW_SPACE_TERRAIN_EVENT}`.
Put the macro in the era to turn every map into space when a game starts:

```
[era]
    ...
    {DW_SPACE_TERRAIN_EVENT}
[/era]
```

The folder also adds a modification, **Dominion War: space terrain**, for trying the terrain
with any era.

## Layout

| Path | What it is |
|---|---|
| `_main.cfg` | binary path, includes, the event macro and the modification |
| `terrain.cfg` | 75 terrain types (generated) |
| `terrain-graphics.cfg` | the drawing rules (generated) |
| `images/terrain/dw/` | 395 hex images (generated) |
| `lua/space_terrain.lua` | the conversion that runs in the prestart event |
| `tools/make_terrain.py` | writes the two `.cfg` files and all the images |
| `tools/convert_map.py` | converts a `.map` file the same way the game does, for screenshots or a fixed space map |
| `tools/gaslib.py`, `gases.py` | the wrapping gas textures (nebulae, Badlands, dust, ice, corona, impassable zones) |
| `tools/art_lib.py`, `asteroids.py`, `badlands.py`, `impassable.py`, `lonecastle.py` | the object art: starfield, asteroids, planets, starbases, outposts, buoys, wreckage |
| `tools/hexmask.png` | Wesnoth's hex mask, so neighbouring hexes join without hairline gaps |
| `tools/sc/` | black holes and pulsar from the Star Control add-on |

## How it is drawn

- **Gas** (nebulae, Badlands, dust, ice, plasma and so on) is one wrapping texture per family
  that repeats every 4 x 4 hexes. Each hex shows the piece at its own place (`mod_x`/`mod_y`
  rules), so neighbouring hexes of one gas form a single cloud with no seams. A soft spill
  reaches a little way into each neighbouring hex of another kind.
- **Objects** (asteroids, planets, starbases, buoys) sit on top, several variations each.
- **Castles** joined to a keep are drydocks; lone castle hexes are defensive outposts with
  battlements, or corner turrets when they stand in gas. Ruined castles have broken shields.
- **Impassable** hexes are drawn by the shape of their cluster: the Void at the map's edge, a
  black hole, pulsar or eddy for a lone hex, a plasma storm, radiation zone or the Briar Patch
  for a thick area, and a chain of gravitational eddies for a thin wall.

## Regenerating

Needs Python 3 with numpy, scipy and Pillow.

```
cd terrain/tools
python3 make_terrain.py          # .cfg files and all images
python3 make_terrain.py --wml    # only the .cfg files
python3 convert_map.py IN.map OUT.map
```

`lua/space_terrain.lua` and `tools/convert_map.py` hold the same mapping. Change both together.

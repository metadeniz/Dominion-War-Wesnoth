# Textured models for the Excelsior, Akira, Nebula and Intrepid

The current sprites for these four ships come from Thingiverse STL print files, which hold shape only, so they can't carry a texture. To get paint on them, the model has to be swapped for a textured one. Every candidate below is a downloadable Sketchfab model. Sketchfab needs a login to download, so you'd download the ones you want and upload the zip here, like the Breen and Galor before.

Pictures: `candidates-textured-ships.png` (Sketchfab's own thumbnails).

Licence key: CC BY is fine for the add-on server. Standard (Sketchfab's free licence) lets us use the model but not share it under an open licence, so the server may refuse it. NC and ND licences don't work for the server.

## Downloaded so far (13 Nov)
The morenostefanuto Excelsior, Akira and Intrepid, the ZEOCMF Nebula and CrustyBread's green B'rel are now in the roster (`new-textured-models.png`, sheet draft 20).
Flat Eric's "Nebula Class (Restyled)" from TrekMeshes came as a 3ds Max `.max` file, which nothing here can open. TrekMeshes' older "Nebula class starship" (original Galaxy parts by Trevor Morris and Ralph Schoberth) came as an LWO file; it's converted and now the roster's Nebula (`nebula-raider-compare.png`). Flat Eric's page also offers an LWO version (converted by Mattc), which would convert the same way.
